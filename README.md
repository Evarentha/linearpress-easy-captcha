Human verification for sign-in, registration and guest comments in LinearPress.

## Features

- Either an image captcha generated by the site (no external service) or Cloudflare Turnstile.
- Choose where it is required: sign-in, registration, guest comments.
- Repeated wrong answers pause the IP address for a while; administrators can lift the pause.

## Where to find it

- `/admin/easy-captcha`: method, where it applies, paused addresses

## Install

Bundled with LinearPress 4. Enable or disable it on the admin Plugins page; the change applies immediately, no restart. In another checkout, run `npm run sync -- easy-captcha` from LinearPress, or put this repository at `src/plugins/easy-captcha` (the directory name must equal the plugin id).

Requires LinearPress ^4.0.0. Works on SQLite and MySQL.
